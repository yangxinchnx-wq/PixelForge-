来自 Core Timeline

src/timeline/
  • 高
    SnapEngine 吸附引擎
    Clip 边缘、播放头、标记点自动吸附对齐，编辑体验质的飞跃。当前系统拖拽无吸附，精确对齐困难。src/timeline/interaction/snapEngine.ts
  • 高
    碰撞检测
    同轨道 Clip 重叠检测 + 自动避让。当前系统允许 Clip 重叠且无任何检测。src/timeline/utils/collision.ts
  • 中
    Selection 多选状态管理
    支持框选、Ctrl+点击多选、Shift 范围选。当前系统只能单选。src/timeline/interaction/selection.ts
  • 中
    BladeTool 刀片工具
    专业切割工具，在任意时间点精确切割 Clip。当前系统有剪切功能但无独立刀片工具。src/timeline/interaction/bladeTool.ts
  • 低
    TimelineVirtualizer 虚拟滚动
    大量 Clip 时只渲染可见区域。当前 Clip 量小，暂不需要。src/timeline/interaction/..

来自 ProTimeline

src/editor/timeline/
  • 高
    CommandHistory 撤销重做
    带事件监听的完整 undo/redo 栈（容量 100），25+ 命令类。当前系统完全无撤销重做，编辑后无法回退。src/editor/timeline/operation/history.ts
  • 高
    完整时间工具函数
    formatTime() HH:MM:SS.mmm + formatTimecode() HH:MM:SS:FF + add/sub/mul/div/clamp。当前 data.ts 只有简单的 MM:SS:FF 格式化。
  • 高
    Clip speed 播放速度
    支持 0.1x~10x 播放速度 + mapToSource 时间映射。当前 Clip 无速度属性。src/editor/timeline/core/clip.ts
  • 中
    TimeRange 区间运算
    交集/并集/重叠检测/平移/裁剪。可用于碰撞检测和渲染优化。src/editor/timeline/core/range.ts
  • 中
    轨道属性增强
    height（可调高度）+ volume（音量）+ color（颜色区分）。当前 Track 无这些属性。src/editor/timeline/core/track.ts
  • 中
    轨道拖拽排序
    拖拽重排轨道顺序 + 同类型轨道重新编号。当前系统无法调整轨道顺序。
  • 中
    多 Clip 操作
    批量删除/移动/复制粘贴/群组/解组。当前系统只能逐个操作。
  • 低
    序列模板库
    内置 + 自定义模板 + localStorage 持久化。对快速创建项目有用但非核心。

来自帧级参数动画

src/stores/timeline.ts
  • 高
    关键帧动画系统
    Keyframe（frame + value + easing）+ ParameterTrack 绑定渲染层参数。当前时间轴无任何动画曲线能力，这是视频编辑器的核心功能。src/editor/timeline/types.ts src/editor/timeline/evaluator.ts
  • 高
    关键帧插值求值器
    linear 线性 + ease smoothstep + hold 保持。给定帧号计算插值后的参数值。可直接集成到当前系统。src/editor/timeline/evaluator.ts
  • 中
    rAF 播放循环
    requestAnimationFrame 驱动的播放循环，按 fps 累积帧步进。当前系统用 setInterval 播放，精度较低。src/editor/timeline/player.ts
  • 中
    CurveCanvas 曲线编辑器
    Canvas 绘制关键帧插值曲线，可视化编辑动画。可集成到 Clip inspector 中。src/components/editor/timeline/CurveCanvas.vue

来自秒级动画系统

src/animation/
  • 高
    bezier 贝塞尔插值
    三次贝塞尔曲线 + cp1/cp2 控制点，电影级动画曲线。比 linear/ease/hold 专业得多。可替换帧级系统的简单缓动。src/animation/types.ts src/animation/curve.ts
  • 中
    EXPRESSION 表达式动画
    用户输入 JS 表达式（如 sin(time) * 0.5）生成程序化动画。高级用户可编程控制参数。
  • 中
    animation/scheduler.ts 帧调度器
    独立的 rAF 帧调度器，支持 startFrameLoop / stop，比直接在组件中管理 rAF 更干净。
  • 低
    GPU Uniform 直接写入
    UniformUpdate → GPUBuffer 直接更新。当前渲染管线不使用这种模式。
  • 低
    inputDriver 输入驱动
    传感器/摄像头/MIDI → 动画。当前项目不需要外部输入驱动。

总结

保留：TimelinePanel.vue + useAppStore（当前系统）

提取合并（16 项）：

高优先级 6 项：CommandHistory · SnapEngine · 碰撞检测 · 关键帧动画+求值器 · bezier 插值 · Clip speed + 时间工具函数
中优先级 10 项：Selection 多选 · 多 Clip 操作 · 轨道排序 · CurveCanvas · rAF 播放 · 轨道属性增强 · TimeRange · EXPRESSION · BladeTool

删除（4 套系统，~100+ 文件）：

1. src/timeline/ — Core Timeline 全部
2. src/editor/timeline/ — ProTimeline 全部
3. src/stores/timeline.ts + src/editor/timeline/types.ts + evaluator.ts + player.ts — 帧级参数动画
4. src/animation/ — 秒级动画全部
+ src/components/timeline/ — Core Timeline UI
+ src/components/editor/timeline/ — 动画时间轴 UI
+ src/components/editor/pro-timeline/ — ProTimeline UI
+ src/components/editor/Timeline.vue — 帧级时间轴 UI

注意：合并的代码将提取到独立文件中（如 src/utils/snapEngine.ts、src/utils/commandHistory.ts 等），不保留原系统结构。
